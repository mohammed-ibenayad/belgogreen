# BelGoGreen — Odoo 19 Modules

Custom Odoo 19 modules for BelGoGreen solar installation operations.

## Modules

### bgg_pv_simulation
Photovoltaic simulation and quotation report generation. Calculates solar production using Google Solar API and PVGIS, generates professional 4-page PDF proposals.

PDF reports are generated by an external Node.js + Puppeteer microservice ([belgogreen-report-service](https://github.com/mohammed-ibenayad/belgogreen-report-service)) deployed separately on the VPS.

### belgogreen_sales_commission
Multi-level hierarchical sales commission system with plans, claims, approvals, and dashboard.

### bgg_custom_dev
Custom extensions: appointment automation, calendar event hooks, project document naming, welcome call deadlines.

## Installation

1. Copy modules to your Odoo addons directory
2. Install Python dependencies: `pip install -r requirements.txt`
3. Update the app list: Settings > Apps > Update Apps List
4. Install each module from the Apps menu

## Report Service Setup

The PV simulation PDF reports require the [belgogreen-report-service](https://github.com/mohammed-ibenayad/belgogreen-report-service) running on the same server.

1. Deploy the service: see the report service repo's README
2. Set Odoo system parameters:
   - `pv_report_service_url` — service URL (default: `http://localhost:3002`)
   - `pv_report_service_api_key` — shared API key

## Dependencies

- Python: see `requirements.txt`
- External APIs: Google Solar API, PVGIS
- Report service: Node.js + Puppeteer (separate deployment)
